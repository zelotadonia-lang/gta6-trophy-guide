GTA 6 Trophy Guide & Tracker: an offline guide and checklist for all 55 Grand Theft Auto VI trophies on PlayStation 5, with a roadmap to the platinum, missable flags, and a cited guide for every trophy. Progress saves in the browser (localStorage), exports to a file and imports back; filters cover story, missable, collectibles, activities and online; a spoiler setting hides story trophy names and descriptions until they are earned. Every guide is written for this page from the official trophy descriptions, and each one names its source.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
